# AeonFast

## Project Overview

**AeonFast** is a mobile application developed to support digital credit services for end users.  
The application allows users to register and complete **KYC** directly through the app. Once approved, users can apply for credit to purchase goods provided by **AEON Credit Service Indonesia**.

The application also provides clear information about active installments, including payment progress and remaining balance.

---

## Core Features (High-Level)

- User **registration** and **KYC** process  
- Credit application flow after KYC approval  
- Product credit selection provided by AEON Credit Service Indonesia  
- Installment information, including:
  - Tenor duration  
  - Amount already paid  
  - Remaining payment balance  
- Other supporting features related to credit and account management  

Detailed financial calculations, approval logic, and risk rules are not exposed.

---

## Technical Stack

- **Mobile**: Kotlin, Java  
- **Architecture**: Modular mobile application structure
